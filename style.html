Les branches Git permettent de travailler sur différentes versions d’un projet sans modifier directement la branche principale. Elles facilitent le développement de nouvelles fonctionnalités, la correction des erreurs et le travail en équipe. La branche principale s’appelle généralement `main` ou `master`. On peut créer une branche avec `git branch`, changer de branche avec `git checkout` ou `git switch`, et fusionner les branches avec `git merge`.
